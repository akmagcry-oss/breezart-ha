# Протоколы и техническая информация

Интеграция поддерживает два сетевых протокола вентиляционных установок Breezart с возможностью автоматического выбора (`auto`).

## 1. Modbus TCP (порт 502 — пульт JLV135, контроллер JL204c7 ПО 1.7.x)

Использует стандартные кадры MBAP + PDU без внешних зависимостей (`FC 0x03` Read Holding Registers, `FC 0x04` Read Input Registers, `FC 0x06` Write Single Register):

### Регистры хранения (`HOLDING`)
- `HOLDING[0]` (`fan_task`) — задание производительности вентилятора (`% × 100`, диапазон `1000..10000`, масштабируется в `1..max_speed`)
- `HOLDING[1]` (`t_task`) — задание температуры воздуха (`°C × 10`, знаковое 16-бит)
- `HOLDING[2]` (`h_task`) — задание относительной влажности (`% × 10`)
- `HOLDING[3]` (`on_off`) — включение/отключение установки (`0` = Выкл, `1` = Рабочий режим, `2` = Отключено по таймеру / Standby)
- `HOLDING[7]` (`mode_hc`) — управление режимами нагрев/охлаждение:
  - `0` — Вентиляция / Лето без охлаждения
  - `1` — Обогрев / Зима
  - `2` — Охлаждение / Лето
  - `3` — Авто Зима/Лето
- `HOLDING[8]` (`scenario`) — номер активного сценария (`0` = нет, `1..8` = сценарии 1–8)
- `HOLDING[100..119]` (`vav_zone_1..20`) — задание производительности воздуха по зонам VAV (`% × 100`, диапазон `0..10000`, масштабируется в `0..max_speed`)

### Входные регистры (`INPUT`)
- `INPUT[10..23]` — основной блок статуса установки:
  - `Cur_mode` — текущий режим работы (`0` = Выкл, `1` = Работа, `2` = Standby по таймеру/расписанию)
  - `Status` — битовая маска состояния установки (включая бит `6` — активность работы по сценарию/таймеру, бит `9` — работа в режиме VAV)
  - `Scen_block` (`INPUT[12]`) — активный сценарий / блок расписания (`младший байт: 1..8`)
  - `Cur_t`, `Cur_h`, `Cur_f` — текущие температура, влажность и производительность вентилятора
  - `Errors`, `Warnings` — битовые маски критических аварий и предупреждений (включая угрозу перегрева, угрозу обморожения и замену фильтра)
- `INPUT[50..63]` — физические датчики `IO_DATA` (температура и влажность на выходе установки, в помещении, на улице, температура теплоносителя)
- `INPUT[10004]` (`Fan0_power`) — потребляемая мощность (`кВт × 100`)
- `INPUT[12005]`, `INPUT[12205]` — текущая загрязнённость фильтров 1 и 2 (`% × 100`)

## 2. Нативный TCP-протокол Breezart (порт 1560 — пульт TPD-283U-H, контроллер JL205)

Текстовый TCP-протокол обмена командами с разделителем `_` и опциональной авторизацией по паролю (в HEX-представлении):

- `VPr07` — получение свойств устройства (диапазоны температуры, влажности и скорости, наличие нагревателя/охладителя/увлажнителя, признак VAV в бите 15 и количество зон VAV `MaxNVAV` `2..20` в битах 8..12 `parts[4]`, версия прошивки)
- `VSt07` — получение текущего состояния (целевая и текущая температура и влажность, режим, скорость, битовые маски состояний и ошибок, разрешение расписания `ScenAllow` в бите 2, номер активного сценария `NumActiveScen` `1..8` в битах 6..9, источник запуска `WhoActivateScen` в битах 10..12, режим VAV в бите 13 и текущее время пульта `Time` `HH:MM` в `parts[7]`)
- `VSens` — получение данных с физических датчиков (температуры, влажность, CO₂, VOC, загрязнённость фильтров)
- `VZLst` — чтение текущих скоростей вентиляторов/клапанов по зонам VAV (`1..20`)
- `VWPwr` — управление питанием (`1` — включить, `0` — выключить)
- `VWTmp` — установка целевой температуры воздуха
- `VWHum` — установка целевой относительной влажности воздуха (`%`)
- `VWSpd` — установка скорости вентилятора
- `VWZSp` — установка скорости в зоне VAV (младшие 5 бит — номер зоны `1..20`, старший байт — скорость `0..max_speed`)
- `VWFtr` — установка режима работы (`1` — Обогрев, `2` — Охлаждение, `3` — Авто, `4` — Вентиляция)
