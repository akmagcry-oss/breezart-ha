# Документация интеграции Breezart для Home Assistant

В этом разделе собрана подробная техническая документация по устройству интеграции, поддерживаемым сущностям и сетевым протоколам вентиляционных установок [Breezart](https://breezart.ru/).

## Разделы документации

- 📊 **[Сенсоры, управление и статусы фильтров](./sensors.md)** — полный перечень базовых и дополнительных сенсоров, бинарных индикаторов аварий, статусов загрязнённости фильтров, элементов управления и индивидуальных переключателей push-уведомлений.
- 🔌 **[Протоколы и техническая информация](./protocols.md)** — описание регистров **Modbus TCP (порт 502)** для пультов `JLV135` / контроллеров `JL204c7` и команд **Native TCP (порт 1560)** для пультов `TPD-283U-H` / контроллеров `JL205`.
- 🗂️ **[Структура проекта](./structure.md)** — архитектура компонента `custom_components/breezart/` и назначение модулей интеграции.
