# Сенсоры, управление и статусы фильтров

Интеграция создаёт **55 базовых и дополнительных сущностей** (и до **75 сущностей** при использовании 20-зонной VAV-системы) в Home Assistant в зависимости от выбранного пресета модели (`400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` или `Custom`).

## Climate (Термостат)

Единая карточка управления климатом (`climate.breezart`):
- **Установка целевой температуры** — по умолчанию **5–35 °C** (определяется автоматически от контроллера либо задаётся в настройках интеграции)
- **Установка целевой влажности** — по умолчанию **30–85 %** (`ClimateEntityFeature.TARGET_HUMIDITY`, границы определяются автоматически от контроллера по `VPr07`)
- **Выбор скорости вентилятора** — по умолчанию **1–10** (с возможностью задания количества скоростей `1..10` в настройках интеграции)
- **Режимы работы** — Обогрев (`heat`) / Охлаждение (`cool`) / Авто (`heat_cool`) / Вентиляция (`fan_only`) / Выключено (`off`)
- **Отображение текущей температуры и влажности**
- **Включение и выключение установки**

## Базовые сенсоры

Активируются по умолчанию для всех моделей:

| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура (точка регулирования) | Текущая температура в точке регулирования (`INPUT[13]` / `VSt07`) |
| 🌡️ Температура подачи (выход установки) | Температура воздуха на выходе установки (`INPUT[50]` / `VSens`) |
| 💨 Скорость вентилятора | Текущая скорость (`0..10`) |
| 🌬️ Расход воздуха (`sensor.breezart_airflow`) | Расчётный объёмный расход воздуха в **м³/ч** по номинальной производительности модели (`400..2000 м³/ч`) и текущей скорости вентилятора (атрибут `nominal_airflow_m3h`) |
| 🔥 Тепловая мощность калорифера (`sensor.breezart_heater_thermal_power`) | Расчётная полезная тепловая мощность нагрева воздуха в **Вт** ($P = 0{,}336 \cdot L \cdot \Delta T$, атрибут `temp_delta_c`) |
| 📈 КПД калорифера (`sensor.breezart_heater_efficiency`) | Расчётный КПД нагрева в **%** (отношение тепловой мощности к потребляемой электрической мощности или степень достижения целевой температуры для водяных калориферов `Aqua`) |
| 💧 Влажность | Относительная влажность (%) |
| 🔄 Режим работы | Обогрев / Охлаждение / Авто-Обогрев / Авто-Охлаждение / Вентиляция |
| ⚙️ Состояние установки | Включено / Выключено / Включение / Выключение |
| 🔧 Загрязнённость фильтра | Процент загрязнения основного фильтра (%) |
| ⚡ Потреблённая энергия | Накопленное энергопотребление в кВт·ч (`TOTAL_INCREASING`, `SensorDeviceClass.ENERGY`) для панели «Энергия» (HA Energy Dashboard) с сохранением состояния после перезапуска |
| 🕒 Активный сценарий / расписание | Текущий сценарий пульта (`Без сценария`, `Сценарий 1..8`, `Отключено по таймеру (Standby)`) с атрибутами `scenario_number`, `schedule_enabled`, `activation_source` и `controller_time` (`HH:MM`) |

## Дополнительные сенсоры

Активируются автоматически по выбранному пресету модели либо включаются вручную в реестре сущностей Home Assistant:

| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура в помещении | Если установлен комнатный датчик (`INPUT[54]`) |
| 🌡️ Температура на улице | Наружный воздух (`INPUT[58]`) |
| 🌡️ Температура теплоносителя | Температура воды в системе (`INPUT[62]`, активен по умолчанию для моделей Aqua) |
| 💧 Заданная влажность | Целевая уставка влажности (`HOLDING[2]` / `VSt07`, %, активен по умолчанию для моделей с увлажнителем) |
| 💧 Влажность (приток / комната / улица) | Дополнительные датчики влажности (`INPUT[52, 56, 60]`) |
| 🌫️ CO₂ | Концентрация углекислого газа (ppm) |
| 🌫️ VOC | Уровень загрязнённости воздуха (ppb) |
| 🔌 Потребляемая мощность | Энергопотребление (`INPUT[10004]`, Вт, активен по умолчанию для моделей Lux) |
| 📊 Фактическая скорость | Реальная производительность вентилятора (`INPUT[17]`, %) |
| 🧹 Фильтры 1–4 | Состояние каждого фильтра (`INPUT[12005, 12205]`) с локализованным текстовым статусом (RU/EN) |

## Статусы фильтров (RU / EN)

Для каждого фильтра рассчитывается процент загрязнённости и текстовый статус на выбранном языке интерфейса:

- ✅ **Отличное / Excellent** (< 30%)
- 🟢 **Хорошее / Good** (30–59%)
- 🟡 **Требуется замена / Replace soon** (60–84%)
- 🔴 **Забит / Clogged** (≥ 85%)

## Бинарные сенсоры

| Сенсор | Описание |
|--------|----------|
| ✅ Установка включена | Текущее состояние питания |
| ⚠️ Предупреждение | Некритическая ошибка или сервисное предупреждение |
| 🚨 Критическая ошибка | Фатальная ошибка системы |
| 🔥 Угроза перегрева | Перегрев калорифера |
| ❄️ Угроза обморожения | Низкая температура воздуха/воды или работа без достаточного обогрева на морозе |
| 🧹 Требуется замена фильтра | Превышен порог загрязнения фильтра |
| 🕒 Работа по таймеру / расписанию | Индикатор активного сценария или ожидания по таймеру на пульте |
| 🌀 Режим VAV активен (`binary_sensor.breezart_vav_mode`) | Индикатор работы VAV-системы с атрибутами `has_vav`, `vav_zones` и `zone_speeds` |

## Управление и переключатели уведомлений

| Объект | Описание |
|--------|----------|
| 🔌 Питание (`switch.breezart_power`) | Включение / выключение установки |
| 🌡️ Заданная температура (`number.breezart_target_temperature`) | Установка целевой температуры (`5..35 °C`) |
| 💧 Заданная влажность (`number.breezart_target_humidity`) | Установка целевой относительной влажности (`30..85 %`) |
| 💨 Скорость вентилятора (`number.breezart_fan_speed`) | Установка скорости вентилятора (`1..10`) |
| 🌀 VAV Зона 1..20 (`number.breezart_vav_zone_1..20`) | Регулировка расхода воздуха по зонам VAV (`0..max_speed`, создаются при наличии VAV) |
| 🔔 Уведомление: Угроза перегрева (`switch.breezart_notify_overheat`) | Вкл/выкл push-уведомлений об угрозе перегрева |
| 🔔 Уведомление: Угроза обморожения (`switch.breezart_notify_freeze`) | Вкл/выкл push-уведомлений об угрозе обморожения |
| 🔔 Уведомление: Замена фильтра (`switch.breezart_notify_filter`) | Вкл/выкл push-уведомлений о необходимости замены фильтра |
| 🔔 Уведомление: Устройство не в сети (`switch.breezart_notify_offline`) | Вкл/выкл push-уведомлений при отключении питания или потере связи |
| 🔔 Уведомление: Устройство в сети (`switch.breezart_notify_online`) | Вкл/выкл push-уведомлений при появлении устройства в сети |
| 🔔 Уведомление: Включение / выключение (`switch.breezart_notify_power`) | Вкл/выкл push-уведомлений о переключении питания установки |
| 🔔 Уведомление: Остальные ошибки (`switch.breezart_notify_other_errors`) | Вкл/выкл push-уведомлений о прочих ошибках и предупреждениях |
