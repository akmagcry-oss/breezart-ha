# Структура проекта

Архитектура пользовательского компонента `custom_components/breezart/` для Home Assistant:

```text
custom_components/breezart/
├── __init__.py           # Основная логика, setup и перезагрузка опций
├── config_flow.py        # UI настройки, выбор модели, протокола и уведомлений
├── coordinator.py        # Клиенты BreezartModbusClient, BreezartTCPClient, координатор и движок уведомлений
├── climate.py            # Климат-контроль (термостат)
├── sensor.py             # Сенсоры (температура, скорость, режим, фильтры...)
├── binary_sensor.py      # Бинарные сенсоры (ошибки, состояние)
├── number.py             # Управление (температура, скорость)
├── switch.py             # Выключатель питания + 7 переключателей уведомлений в настройках устройства
├── diagnostics.py        # Выгрузка диагностики устройства в 1 клик (со скрытием пароля и IP)
├── const.py              # Все константы протоколов, карта регистров JL204c7, пресеты и словари RU/EN
├── brand/icon.png        # Иконка интеграции для Home Assistant и HACS
├── manifest.json         # Метаданные HACS (v1.3.0)
├── strings.json          # Базовые строки локализации
└── translations/         # Переводы интерфейса и сущностей (ru.json, en.json)
```

## Назначение ключевых модулей

- **`coordinator.py`** — содержит реализации двух сетевых клиентов (`BreezartModbusClient` для порта `502` и `BreezartTCPClient` для порта `1560`), логику автоопределения протокола, координатор опроса `BreezartCoordinator` с периодом обновления 3 секунды, механизм оптимистичного удержания команд (`6 с`) и систему отправки push-уведомлений с защитой от дублирования и дребезга.
- **`const.py`** — единый источник констант протоколов, карты регистров Modbus для контроллера `JL204c7`, пресетов моделей (`MODEL_PRESETS`) и двуязычных словарей перевода (`RU` / `EN`).
- **`config_flow.py`** — мастер первоначальной настройки и окно «Настроить» (`OptionsFlow`) для изменения параметров подключения, количества скоростей, границ температур и переключателей уведомлений без переустановки интеграции.
