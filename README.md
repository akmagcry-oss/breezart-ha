# Breezart Home Assistant Integration

Неофициальная интеграция приточно-вытяжных вентиляционных установок [Breezart](https://breezart.ru/) для [Home Assistant](https://www.home-assistant.io/).

Обеспечивает прямое локальное управление и мониторинг вент-установок по локальной сети без облачных сервисов с автоматическим определением протокола подключения (**Modbus TCP** и **Native TCP**).

## Возможности

- 🌡️ **Климат-контроль и управление влажностью (Climate & Number Entities)** — единая карточка термостата для включения/выключения установки, задания целевой температуры (по умолчанию `5–35 °C`), **управления целевой влажностью** (`30–85 %`, `ClimateEntityFeature.TARGET_HUMIDITY` и `number.breezart_target_humidity`), выбора скорости вентилятора (`1–10`) и переключения режимов работы (`Обогрев`, `Охлаждение`, `Авто`, `Вентиляция`, `Выключено`).
- 🌀 **Поддержка VAV-зонирования (до 20 зон)** — автоматическое определение VAV-системы (`VPr07` на Native TCP или задание количества зон `2..20` в настройках для Modbus TCP), создание индивидуальных регуляторов расхода воздуха по зонам (`number.breezart_vav_zone_1..20`, `0..max_speed` via `VWZSp` / `HOLDING[100..119]`) и бинарного индикатора режима VAV (`binary_sensor.breezart_vav_mode`).
- 🔌 **Автопоиск в локальной сети, перенастройка (Reconfigure) и смена пароля (Reauth)** — автоматическое сканирование локальной подсети `/24` при добавлении интеграции с определением IP, порта и протокола (**Modbus TCP 502** для `JLV135`/`JL204c7` и **Native TCP 1560** для `TPD-283U-H`/`JL205`), а также смена IP-адреса, порта, протокола и пароля через меню **«Перенастроить» (`Reconfigure`)** или диалог обновления пароля (**`Reauth`**) без удаления интеграции и потери истории.
- ⚡ **Панель «Энергия» и расчётные сенсоры воздушного потока / калорифера** — сенсор накопленной энергии в **кВт·ч** (`TOTAL_INCREASING`, `SensorDeviceClass.ENERGY`) с сохранением показаний при перезапуске Home Assistant, мониторинг мгновенной потребляемой мощности (Вт), а также **расчётные сенсоры расхода воздуха в м³/ч** (`sensor.breezart_airflow`), **тепловой мощности калорифера в Вт** (`sensor.breezart_heater_thermal_power`, $P = 0{,}336 \cdot L \cdot \Delta T$) и **КПД калорифера в %** (`sensor.breezart_heater_efficiency`).
- 🕒 **Чтение расписаний / сценариев и таймера пульта** — отображение текущего сценария (`Сценарий 1..8`, `Отключено по таймеру (Standby)` или `Без сценария`), источника активации (`Таймер 1/2`, `Вручную с пульта`, `Внешний сигнал`), разрешения работы по расписанию, часов пульта (`HH:MM`) и бинарного индикатора активности таймера/расписания.
- 🛠️ **Панель «Ремонт» (HA Repairs) и выгрузка диагностики в 1 клик** — автоматическое создание карточек проблем в разделе **«Ремонт»** при загрязнении фильтра (`≥ 85%`), угрозе перегрева, обморожения или ошибках контроллера (с автозакрытием после устранения), а также выгрузка JSON-диагностики устройства со скрытием пароля и IP.
- 📊 **Сенсоры микроклимата и фильтров** — мониторинг температур (точка регулирования, подача, помещение, улица, теплоноситель), влажности, уровня CO₂ и VOC, загрязнённости фильтров 1–4 (с текстовыми статусами) и бинарных индикаторов аварий.
- 🔔 **Push-уведомления о важных событиях (`notify.mobile_app_*`)** — оповещения на телефон об угрозе перегрева, угрозе обморожения, необходимости замены фильтра, потере/восстановлении связи, включении/выключении установки и других ошибках с возможностью индивидуального отключения каждого уведомления в настройках устройства.
- 🤖 **Готовые шаблоны автоматизаций (Home Assistant Blueprints)** — 4 готовых чертежа автоматизаций (автопроветривание по датчику CO₂ с гистерезисом, ночной тихий режим, эко-режим «Нет дома» и пауза/снижение скорости при открытии окна), которые автоматически устанавливаются в `<config>/blueprints/automation/breezart/` при запуске интеграции.
- 🧩 **Пресеты моделей и гибкая настройка** — готовые профили для линеек `Lux` и `Aqua`, настройка количества скоростей вентилятора (`1..10`) и границ обогрева воздуха, двусторонняя синхронизация с настенным пультом каждые 3 секунды и полная локализация (`RU` / `EN`).

## Совместимость

- **Модели установок**: Breezart `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` и другие установки с контроллерами JetLogic **JL204c7** (ПО 1.7.x) и **JL205**
- **Пульты управления**:
  - **JLV135** (Wi-Fi модуль Espressif, протокол **Modbus TCP**, порт **502**, Slave ID **1**, пароль не требуется)
  - **TPD-283U-H** (протокол **Native TCP**, порт **1560**, с паролем удалённого доступа)
- **Home Assistant**: `2024.11.0` и новее

## Установка и настройка

### Установка через [HACS](https://hacs.xyz/) (рекомендуется)

1. Добавьте репозиторий в HACS [по ссылке](https://my.home-assistant.io/redirect/hacs_repository/?owner=akmagcry-oss&repository=breezart-ha&category=integration), либо
1.1. В HACS откройте **⋯** → **Пользовательские репозитории**.
1.2. Добавьте репозиторий `https://github.com/akmagcry-oss/breezart-ha` с категорией **Интеграция** (`Integration`).
2. Найдите **Breezart** в списке интеграций HACS и нажмите **Установить**.
3. Перезапустите Home Assistant.
4. Перейдите в **Настройки** → **Устройства и службы** → **Добавить интеграцию** → **Breezart**.

### Ручная установка

1. Скачайте репозиторий `https://github.com/akmagcry-oss/breezart-ha`.
2. Скопируйте папку `custom_components/breezart` в директорию `<config>/custom_components/` вашего Home Assistant.
3. Перезапустите Home Assistant и добавьте интеграцию **Breezart** через раздел **Настройки** → **Устройства и службы**.

### Параметры настройки

При добавлении интеграции автоматически выполняется поиск установок Breezart в локальной сети `/24` (с автозаполнением IP-адреса, порта и протокола или выбором из списка найденных устройств). Также в любой момент по кнопке **«Настроить»** на карточке интеграции можно задать:
- **Модель установки**: `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` или `Custom`
- **Протокол подключения**: `Автоопределение (502 / 1560)`, `Modbus TCP (порт 502)` или `Native TCP (порт 1560)`
- **Хост и порт**: IP-адрес установки (подставляется автоматически при обнаружении в сети, либо можно указать `auto` для повторного сканирования), порт `502` или `1560`, адрес Modbus Slave ID (`1` по умолчанию) и пароль (только для `TPD-283U-H`)
- **Диапазоны регулирования и VAV**: количество скоростей вентилятора (`1–10`, по умолчанию `10`), минимальная (`5 °C`) и максимальная (`35 °C`) температура нагрева, количество зон VAV (`0` — автоопределение от контроллера, либо `2–20` зон)
- **Уведомления**: сервис уведомлений (`notify.notify` по умолчанию с автоотправкой на `notify.mobile_app_*`) и индивидуальные переключатели для каждого из 7 типов событий
