Полнофункциональная интеграция систем вентиляции **Breezart** для Home Assistant (`v1.0.0`).  
Использует **нативный TCP-протокол** (порт 1560) для быстрого и надёжного управления.

## Установка через HACS

## ✨ Особенности

- 🌡️ **Climate Entity (Термостат)** — единое управление температурой, режимами и скоростью вентилятора
- 🧩 **Преднастройки моделей (`MODEL_PRESETS`)** — встроенные профили для **400 Lux, 550 Lux, 550 Aqua, 700 Lux, 1000 Lux, 1000 Aqua, 2000 Lux** и автоопределения (`VPr07`)
- 🌐 **Полная интернационализация (RU / EN)** — поддержка русского и английского языков для всех 37 сущностей, состояний ENUM-сенсоров, статусов фильтров и мастера настройки
- ⚡ **Мгновенный отклик UI** — optimistic updates с удержанием 6 секунд для плавного управления
- 📊 **Расширенные сенсоры** — температура, влажность, CO₂, VOC, состояние фильтров
- 🔄 **Двусторонняя синхронизация** — изменения с пульта автоматически отображаются в HA (3 секунды)
- 🔌 **Нативный протокол** — прямое TCP-подключение без Modbus, оптимизированный опрос (3/30 сек)

## 🔧 Совместимость

- **Модели**: Breezart 400 Lux, 550 Lux, 550 Aqua, 700 Lux, 1000 Lux, 1000 Aqua, 2000 Lux и другие с контроллером JetLogic JL205
- **Контроллер**: TPD-283U-H с подключением к локальной сети
- **Требования**: Активированный режим удалённого управления с паролем
- **Home Assistant**: 2023.1.0+

## 🎯 Возможности

### Climate (Термостат)
Единая карточка управления климатом:
- 🌡️ Установка целевой температуры (10–30 °C или 15–30 °C в зависимости от модели)
- 💨 Выбор скорости вентилятора (1–8 или 1–10 в зависимости от модели)
- 🔄 Режимы: Обогрев / Охлаждение / Авто / Вентиляция / Выключено
- 📈 Отображение текущей температуры
- ⚡ Включение/выключение установки

### Сенсоры (базовые + авто-активация по пресету модели)
| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура (точка регулирования) | Текущая температура в точке регулирования (`VSt07`) |
| 🌡️ Температура подачи (выход установки) | Температура воздуха на выходе установки (`VSens`) |
| 💨 Скорость вентилятора | Текущая скорость (`0..8` / `0..10`) |
| 💧 Влажность | Относительная влажность (%) |
| 🔄 Режим работы | Обогрев / Охлаждение / Авто-Обогрев / Авто-Охлаждение / Вентиляция |
| ⚙️ Состояние установки | Включено / Выключено / Включение / Выключение |
| 🔧 Загрязнённость фильтра | Процент загрязнения (%) |

### Дополнительные сенсоры
Активируются автоматически по выбранному пресету модели либо включаются вручную:
| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура в помещении | Если установлен комнатный датчик |
| 🌡️ Температура на улице | Наружный воздух |
| 🌡️ Температура теплоносителя | Температура воды в системе (активен по умолчанию для моделей Aqua) |
| 💧 Влажность (приток/комната/улица) | Дополнительные датчики влажности |
| 🌫️ CO₂ | Концентрация углекислого газа (ppm) |
| 🌫️ VOC | Уровень загрязнённости воздуха (ppb) |
| 🔌 Потребляемая мощность | Энергопотребление (Вт, активен по умолчанию для моделей Lux) |
| 📊 Фактическая скорость | Реальная скорость вентилятора (%) |
| 🧹 Фильтры 1–4 | Состояние каждого фильтра с локализованным текстовым статусом (RU/EN) |

**Статусы фильтров (RU / EN):**
- ✅ **Отличное / Excellent** (< 30%)
- 🟢 **Хорошее / Good** (30–59%)
- 🟡 **Требуется замена / Replace soon** (60–84%)
- 🔴 **Забит / Clogged** (≥ 85%)

### Бинарные сенсоры
| Сенсор | Описание |
|--------|----------|
| ✅ Установка включена | Текущее состояние питания |
| ⚠️ Предупреждение | Некритическая ошибка |
| 🚨 Критическая ошибка | Фатальная ошибка системы |
| 🔥 Угроза перегрева | Перегрев калорифера |
| 🧹 Требуется замена фильтра | Фильтр загрязнён |

### Управление
| Объект | Описание |
|--------|----------|
| 🔌 Питание (`switch`) | Включение / выключение установки |
| 🌡️ Заданная температура (`number`) | Установка целевой температуры |
| 💨 Скорость вентилятора (`number`) | Установка скорости |

## Установка

### Способ 1: HACS (рекомендуется)

1. В HACS → Интеграции → ⋯ → Пользовательские репозитории
2. Добавить: `https://github.com/akmagcry-oss/breezart-ha`
3. 📦 **Установка**: [HACS](https://hacs.xyz/) → Интеграции → Breezart → Установить (`v1.0.0`)
4. 🔄 **Перезапуск**: Home Assistant → Перезапустить
5. ⚙️ **Настройка**: Настройки → Устройства → Интеграции → Добавить интеграцию → Breezart

### Способ 2: Ручная установка

1. Скачать репозиторий `https://github.com/akmagcry-oss/breezart-ha`
2. Скопировать папку `custom_components/breezart` в `<config>/custom_components/`
3. Перезапустить Home Assistant
4. Настройки → Интеграции → + → Breezart

## Настройка

При добавлении интеграции укажите:
- **Модель установки**: `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` или `Custom`
- **Хост**: IP-адрес Breezart (например, `192.168.1.121`)
- **Порт**: `1560` (стандартный)
- **Пароль**: Пароль из настроек контроллера TPD-283U-H

## Структура

```
custom_components/breezart/
├── __init__.py           # Основная логика, setup и перезагрузка опций
├── config_flow.py        # UI настройки и выбор пресета модели (OptionsFlow)
├── coordinator.py        # TCP-клиент и координатор данных
├── climate.py            # Климат-контроль (термостат)
├── sensor.py             # Сенсоры (температура, скорость, режим, фильтры...)
├── binary_sensor.py      # Бинарные сенсоры (ошибки, состояние)
├── number.py             # Управление (температура, скорость)
├── switch.py             # Выключатель питания
├── const.py              # Все константы протокола, пресеты моделей и словари RU/EN
├── manifest.json         # Метаданные HACS (v1.0.0)
├── strings.json          # Базовые строки локализации
└── translations/         # Переводы (ru.json, en.json)
```

## 📝 Протокол и техническая информация

Интеграция использует нативный TCP-протокол Breezart (порт 1560):
- `VPr07` — получение свойств устройства (диапазоны температуры/скорости, версия прошивки)
- `VSt07` — получение текущего состояния (температура, режим, скорость, ошибки)
- `VSens` — получение данных с сенсоров (температуры, влажность, CO₂, VOC, фильтры)
- `VWPwr` — управление питанием (вкл/выкл)
- `VWTmp` — установка целевой температуры
- `VWSpd` — установка скорости вентилятора
- `VWFtr` — установка режима работы
