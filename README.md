Полнофункциональная интеграция систем вентиляции **Breezart** для Home Assistant (`v1.2.1`).  
Поддерживает как **Modbus TCP (порт 502)** (пульты **JLV135**, контроллеры **JL204c7**), так и **нативный TCP-протокол (порт 1560)** (пульты **TPD-283U-H**, контроллеры **JL205**) с автоматическим определением протокола.

## ✨ Особенности

- 🌡️ **Climate Entity (Термостат)** — единое управление температурой, режимами и скоростью вентилятора
- 🔌 **Два протокола с автоопределением (`auto`)** — работа через **Modbus TCP (порт 502)** без внешних библиотек (`JLV135` / `JL204c7 v1.7.x`) и **Native TCP (порт 1560)** (`TPD-283U-H`)
- 🔔 **Уведомления о важных событиях на телефон (`notify.mobile_app_*`)** — мгновенные push-уведомления об угрозе перегрева, угрозе обморожения, замене фильтра, потере/восстановлении связи, включении/выключении и других ошибках с индивидуальными переключателями отключения в настройках устройства
- 🧩 **Преднастройки моделей (`MODEL_PRESETS`)** — встроенные профили для **400 Lux, 550 Lux, 550 Aqua, 700 Lux, 1000 Lux, 1000 Aqua, 2000 Lux** и автоопределения (`VPr07` / `Modbus`)
- 🌐 **Полная интернационализация (RU / EN)** — поддержка русского и английского языков для всех 44 сущностей, состояний ENUM-сенсоров, статусов фильтров и мастера настройки
- ⚡ **Мгновенный отклик UI** — optimistic updates с удержанием 6 секунд для плавного управления
- 📊 **Расширенные сенсоры** — температура, влажность, CO₂, VOC, состояние фильтров
- 🔄 **Двусторонняя синхронизация** — изменения с пульта автоматически отображаются в HA (3 секунды)

## 🔧 Совместимость

- **Модели**: Breezart 400 Lux, 550 Lux, 550 Aqua, 700 Lux, 1000 Lux, 1000 Aqua, 2000 Lux и другие с контроллерами JetLogic **JL204c7** (ПО 1.7.x) и **JL205**
- **Пульты управления**:
  - **JLV135** (Wi-Fi модуль Espressif, протокол **Modbus TCP**, порт **502**, Slave ID **1**, пароль не требуется)
  - **TPD-283U-H** (протокол **Native TCP**, порт **1560**, с паролем удалённого доступа)
- **Home Assistant**: 2023.1.0+

## 🎯 Возможности

### Climate (Термостат)
Единая карточка управления климатом:
- 🌡️ Установка целевой температуры (по умолчанию **5–35 °C**, определяется автоматически от контроллера либо задаётся в настройках интеграции)
- 💨 Выбор скорости вентилятора (по умолчанию **1–10**, с возможностью задания количества скоростей `1..10` в настройках интеграции)
- 🔄 Режимы: Обогрев / Охлаждение / Авто / Вентиляция / Выключено
- 📈 Отображение текущей температуры
- ⚡ Включение/выключение установки

### Сенсоры (базовые + авто-активация по пресету модели)
| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура (точка регулирования) | Текущая температура в точке регулирования (`INPUT[13]` / `VSt07`) |
| 🌡️ Температура подачи (выход установки) | Температура воздуха на выходе установки (`INPUT[50]` / `VSens`) |
| 💨 Скорость вентилятора | Текущая скорость (`0..10`) |
| 💧 Влажность | Относительная влажность (%) |
| 🔄 Режим работы | Обогрев / Охлаждение / Авто-Обогрев / Авто-Охлаждение / Вентиляция |
| ⚙️ Состояние установки | Включено / Выключено / Включение / Выключение |
| 🔧 Загрязнённость фильтра | Процент загрязнения (%) |

### Дополнительные сенсоры
Активируются автоматически по выбранному пресету модели либо включаются вручную:
| Сенсор | Описание |
|--------|----------|
| 🌡️ Температура в помещении | Если установлен комнатный датчик (`INPUT[54]`) |
| 🌡️ Температура на улице | Наружный воздух (`INPUT[58]`) |
| 🌡️ Температура теплоносителя | Температура воды в системе (`INPUT[62]`, активен по умолчанию для моделей Aqua) |
| 💧 Влажность (приток/комната/улица) | Дополнительные датчики влажности (`INPUT[52, 56, 60]`) |
| 🌫️ CO₂ | Концентрация углекислого газа (ppm) |
| 🌫️ VOC | Уровень загрязнённости воздуха (ppb) |
| 🔌 Потребляемая мощность | Энергопотребление (`INPUT[10004]`, Вт, активен по умолчанию для моделей Lux) |
| 📊 Фактическая скорость | Реальная скорость вентилятора (`INPUT[17]`, %) |
| 🧹 Фильтры 1–4 | Состояние каждого фильтра (`INPUT[12005, 12205]`) с локализованным текстовым статусом (RU/EN) |

**Статусы фильтров (RU / EN):**
- ✅ **Отличное / Excellent** (< 30%)
- 🟢 **Хорошее / Good** (30–59%)
- 🟡 **Требуется замена / Replace soon** (60–84%)
- 🔴 **Забит / Clogged** (≥ 85%)

### Бинарные сенсоры
| Сенсор | Описание |

| 🧹 Требуется замена фильтра | Фильтр загрязнён |

| 🔔 Уведомление: Устройство в сети (`switch.breezart_notify_online`) | Вкл/выкл push-уведомлений при появлении устройства в сети |

| 🔔 Уведомление: Остальные ошибки (`switch.breezart_notify_other_errors`) | Вкл/выкл push-уведомлений о прочих ошибках и предупреждениях |

## Установка

### Способ 1: HACS (рекомендуется)

1. В HACS → Интеграции → ⋯ → Пользовательские репозитории
2. Добавить: `https://github.com/akmagcry-oss/breezart-ha`
3. 📦 **Установка**: [HACS](https://hacs.xyz/) → Интеграции → Breezart → Установить (`v1.2.1`)
4. 🔄 **Перезапуск**: Home Assistant → Перезапустить
5. ⚙️ **Настройка**: Настройки → Устройства → Интеграции → Добавить интеграцию → Breezart

### Способ 2: Ручная установка

1. Скачать репозиторий `https://github.com/akmagcry-oss/breezart-ha`
2. Скопировать папку `custom_components/breezart` в `<config>/custom_components/`
3. Перезапустить Home Assistant
4. Настройки → Интеграции → + → Breezart

## Настройка

При добавлении интеграции (а также в любой момент через кнопку **«Настроить»** на карточке интеграции) можно задать:
- **Модель установки**: `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` или `Custom`
- **Протокол подключения**:
  - `Автоопределение (Modbus TCP 502 / Native TCP 1560)` — автоматически проверит порт `502` (Modbus TCP) и `1560` (Native TCP)
  - `Modbus TCP (порт 502 — пульт JLV135 / JL204c7)`
  - `Native TCP (порт 1560 — пульт TPD-283U-H)`
- **Хост**: IP-адрес Breezart (например, `192.168.2.38` или `192.168.1.121`)
- **Порт**: `502` (для Modbus TCP / пульта JLV135) или `1560` (для Native TCP / пульта TPD-283U-H)
- **Адрес устройства Modbus (Slave ID)**: `1` (по умолчанию)
- **Количество скоростей вентилятора**: `10` (по умолчанию, диапазон `1–10`)
- **Минимальная температура нагрева (°C)**: `5` (по умолчанию, диапазон `5–30 °C`)
- **Максимальная температура нагрева (°C)**: `35` (по умолчанию, диапазон `15–45 °C`)
- **Сервис уведомлений Home Assistant**: `notify.notify` (по умолчанию; также автоматически отправляет на все подключённые телефоны `notify.mobile_app_*`)
- **Индивидуальные переключатели уведомлений**: возможность по отдельности включить или отключить любой из 7 типов уведомлений как в окне «Настроить», так и прямо на карточке устройства в блоке «Настройки» (`Configuration`)
- **Пароль**: требуется только для пультов TPD-283U-H (порт 1560)

## 📝 Протоколы и техническая информация

### 1. Modbus TCP (порт 502 — пульт JLV135, контроллер JL204c7 ПО 1.7.x)
Использует стандартные кадры MBAP + PDU без внешних зависимостей (`FC 0x03`, `0x04`, `0x06`):
- `HOLDING[0]` (`fan_task`) — задание производительности вентилятора (`% × 100`, `1000..10000`)
- `HOLDING[1]` (`t_task`) — задание температуры воздуха (`°C × 10`, знаковое 16-бит)
- `HOLDING[2]` (`h_task`) — задание относительной влажности (`% × 10`)
- `HOLDING[3]` (`on_off`) — включение/отключение установки (`0` = Выкл, `1` = Рабочий режим)
- `HOLDING[7]` (`mode_hc`) — управление режимами нагрев/охлаждение (`0` = Вентиляция/Лето, `1` = Обогрев/Зима, `2` = Охлаждение/Лето, `3` = Авто Зима/Лето)
- `INPUT[10..23]` — статус установки (`Cur_mode`, битовая маска `Status`, `Cur_t`, `Cur_h`, `Cur_f`, битовые маски аварий `Errors` и `Warnings`)
- `INPUT[50..63]` — физические датчики `IO_DATA` (температура и влажность на выходе установки, в помещении, на улице, температура теплоносителя)
- `INPUT[10004]` (`Fan0_power`) — потребляемая мощность (`кВт × 100`)
- `INPUT[12005]`, `INPUT[12205]` — текущая загрязнённость фильтров 1 и 2 (`% × 100`)

### 2. Нативный TCP-протокол Breezart (порт 1560 — пульт TPD-283U-H)
- `VPr07` — получение свойств устройства (диапазоны температуры/скорости, версия прошивки)
- `VSt07` — получение текущего состояния (температура, режим, скорость, ошибки)
- `VSens` — получение данных с сенсоров (температуры, влажность, CO₂, VOC, фильтры)
- `VWPwr` — управление питанием (вкл/выкл)
- `VWTmp` — установка целевой температуры
- `VWSpd` — установка скорости вентилятора
- `VWFtr` — установка режима работы
