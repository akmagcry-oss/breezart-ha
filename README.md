# Breezart Home Assistant Integration

Неофициальная интеграция приточно-вытяжных вентиляционных установок [Breezart](https://breezart.ru/) для [Home Assistant](https://www.home-assistant.io/).

Обеспечивает прямое локальное управление и мониторинг вент-установок по локальной сети без облачных сервисов с автоматическим определением протокола подключения (**Modbus TCP** и **Native TCP**).

## Возможности

- 🌡️ **Климат-контроль (Climate Entity)** — единая карточка термостата для включения/выключения установки, задания целевой температуры (по умолчанию `5–35 °C`), выбора скорости вентилятора (`1–10`) и переключения режимов работы (`Обогрев`, `Охлаждение`, `Авто`, `Вентиляция`, `Выключено`).
- 🔌 **Два протокола с автоопределением (`auto`)** — работа через **Modbus TCP (порт 502)** без внешних библиотек (пульты `JLV135`, контроллеры `JL204c7`) и **Native TCP (порт 1560)** (пульты `TPD-283U-H`, контроллеры `JL205`).
- 📊 **Сенсоры и диагностика** — мониторинг температур (точка регулирования, подача, помещение, улица, теплоноситель), влажности, уровня CO₂ и VOC, потребляемой мощности, загрязнённости фильтров (с текстовыми статусами) и бинарных индикаторов аварий (`Угроза перегрева`, `Угроза обморожения`, `Требуется замена фильтра` и др.).
- 🔔 **Push-уведомления о важных событиях (`notify.mobile_app_*`)** — оповещения на телефон об угрозе перегрева, угрозе обморожения, необходимости замены фильтра, потере/восстановлении связи, включении/выключении установки и других ошибках с возможностью индивидуального отключения каждого уведомления в настройках устройства.
- 🧩 **Пресеты моделей и гибкая настройка** — готовые профили для линеек `Lux` и `Aqua`, настройка количества скоростей вентилятора (`1..10`) и границ обогрева воздуха, двусторонняя синхронизация с настенным пультом каждые 3 секунды и полная локализация (`RU` / `EN`).

## Совместимость

- **Модели установок**: Breezart `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` и другие установки с контроллерами JetLogic **JL204c7** (ПО 1.7.x) и **JL205**
- **Пульты управления**:
  - **JLV135** (Wi-Fi модуль Espressif, протокол **Modbus TCP**, порт **502**, Slave ID **1**, пароль не требуется)
  - **TPD-283U-H** (протокол **Native TCP**, порт **1560**, с паролем удалённого доступа)
- **Home Assistant**: `2023.1.0` и новее

## Установка и настройка

### Установка через [HACS](https://hacs.xyz/) (рекомендуется)

1. Добавьте репозиторий в HACS [по ссылке](https://my.home-assistant.io/redirect/hacs_repository/?owner=akmagcry-oss&repository=breezart-ha&category=integration), либо
1.1. В HACS откройте **⋯** → **Пользовательские репозитории**.
1.2. Добавьте репозиторий `https://github.com/akmagcry-oss/breezart-ha` с категорией **Интеграция** (`Integration`).
2. Найдите **Breezart** в списке интеграций HACS и нажмите **Установить**.
3. Перезапустите Home Assistant.
4. Перейдите в **Настройки** → **Устройства и службы** → **Добавить интеграцию** → **Breezart**.

### Ручная установка

1. Скачайте репозиторий `https://github.com/akmagcry-oss/breezart-ha`.
2. Скопируйте папку `custom_components/breezart` в директорию `<config>/custom_components/` вашего Home Assistant.
3. Перезапустите Home Assistant и добавьте интеграцию **Breezart** через раздел **Настройки** → **Устройства и службы**.

### Параметры настройки

При добавлении интеграции (а также в любой момент по кнопке **«Настроить»** на карточке интеграции) можно задать:
- **Модель установки**: `400 Lux`, `550 Lux`, `550 Aqua`, `700 Lux`, `1000 Lux`, `1000 Aqua`, `2000 Lux` или `Custom`
- **Протокол подключения**: `Автоопределение (502 / 1560)`, `Modbus TCP (порт 502)` или `Native TCP (порт 1560)`
- **Хост и порт**: IP-адрес установки (например, `192.168.1.8`), порт `502` или `1560`, адрес Modbus Slave ID (`1` по умолчанию) и пароль (только для `TPD-283U-H`)
- **Диапазоны регулирования**: количество скоростей вентилятора (`1–10`, по умолчанию `10`), минимальная (`5 °C`) и максимальная (`35 °C`) температура нагрева
- **Уведомления**: сервис уведомлений (`notify.notify` по умолчанию с автоотправкой на `notify.mobile_app_*`) и индивидуальные переключатели для каждого из 7 типов событий
